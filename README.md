# DualForm-T128

Research implementation of a 24-round tweakable block cipher: 128-bit blocks, 256-bit keys, 128-bit public tweaks. These sizes are not a security rating. No authentication or encryption mode is provided.

[한국어](README.ko.md) · [Normative specification](docs/spec_ko.md) · [Progress](docs/progress_ko.md)

Requires C11, CMake 3.20+, OpenSSL 3.x, and Python 3.11+ for validation. This repository implements the attached specification without importing an older implementation. Research only; cryptographic security is not established. A distribution license has not yet been selected by the owner. OpenSSL is an external dependency under its own license.
