# 보안 연구와 한계

이 후보는 인증·AEAD·운용모드를 제공하지 않는 연구용 primitive입니다. 128비트 블록·256비트 키는 검증된 보안 강도를 뜻하지 않습니다.

## 이번 코어에서 실제 재현한 결과

- 역함수: 짝수 선형층 rank 64, 64개 기저, 경계 및 결정적 10,000워드의 양방향 F 역변환 통과.
- **2라운드:** 외부 평문·암호문 한 쌍에서 SK0·SK1 복구, 1,024조합에서 별도 평문으로 확인했습니다. 마스터키 또는 24라운드 키 복구가 아닙니다.
- 공개 tweak XOR 양성 대조군: 2라운드 상쇄 등식 1,024/1,024. 현재 키 의존 스케줄에서 동일 등식은 0/1,024로 관측되었습니다. 관측 0회는 공격 불가능성의 증명이 아닙니다.
- 고정 차분: 8키 × 6라운드 설정 × 32,768쌍 = 1,572,864쌍. 4라운드의 고정 출력 bit1 반전율은 **99.942017~99.966431%**입니다. 4라운드 통계 구별 편향이며 키 복구나 24라운드 공격으로 확장해 표현하지 않습니다.
- 관련 tweak: 8키 × 5라운드 × 4차분 × 4,096쌍 = 655,360쌍, 160설정. 20,480개 출력 bit 검정을 보수적으로 보정했을 때 Hoeffding 상한이 0.05 미만인 관측은 0개입니다. 사전 고정된 범위 밖의 공격 저항성은 말하지 않습니다.

원시 counts·고정 차분 로그 상한·관련 tweak 설정별 최소 로그 상한·실행 시간·명세 및 코어 해시는 [baseline-full.json](../research/results/baseline-full.json)에 있습니다. 실행 상태는 `completed`, 소요 시간은 9.146초입니다. 관련 tweak 개별 bit 상한은 보존한 counts에서 bounds(k,n,20480)으로 정확히 다시 계산합니다. 개별 상한 사전을 생략한 압축 변환과 원본 JSON 해시를 기록합니다. 이 파일의 manifest가 측정에 사용한 소스를 식별합니다. 이전 감사의 소수점 수치를 복사하지 않았습니다.

## 통계 모델

독립 Bernoulli 근사에서 Hoeffding 상한을 계산합니다. 로그를 보존하며 underflow를 수학적 확률 0으로 적지 않습니다. 고정 차분은 48검정, 관련 tweak는 20,480검정으로 보정합니다. 이는 trail/hull 확률 증명이 아니며 p-value를 CI 합격선으로 삼지 않습니다. 추가 탐색은 독립 holdout이 필요합니다.

## 미해결 연구

전체 24라운드 안전성 증명, SAT/MILP 전체 탐색, 차분 hull 합산, 관련키·integral·boomerang·MITM 분석은 완료하지 않았습니다. 전체 라운드에서 공격을 찾지 않았다는 사실만으로 실제 기밀용 사용을 승인하지 않습니다. 코어를 임의로 변경하지 않고 관측한 구조적 약점을 기록합니다. 상수시간 보편 증명도 제공하지 않습니다.
