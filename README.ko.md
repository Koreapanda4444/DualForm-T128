# DualForm-T128

128비트 블록·256비트 키·128비트 공개 tweak를 사용하는 24라운드 연구용 암호입니다. 비트 크기는 보안 강도가 아닙니다. 인증 기능과 운용모드는 제공하지 않습니다.

[English](README.md) · [규범 명세](docs/spec_ko.md) · [진행표](docs/progress_ko.md)

C11, CMake 3.20+, OpenSSL 3.x가 필요하며 검증 도구는 Python 3.11+를 사용합니다. 소유자의 배포 라이선스 선택은 미정입니다. OpenSSL의 의존성 라이선스는 별도 적용됩니다.
